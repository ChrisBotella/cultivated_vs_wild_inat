# cultivated_vs_wild_inat
This data and R code aims at reproducing the analyses, tables and figures of the manuscript "Automated detection of wild and cultivated plants in citizen science records".

### Dependencies

You'll need to install the following R packages: 

- magrittr
- rinat
- raster
- rgeos
- rgbif
- ggplot2
- sf
- ggmap
- leaflet
- rpart
- glmnet
- randomForest
- jsonlite
- dplyr
